# Standalone portfolio site

`index.html` is a dependency-free website version of the profile. Preview it by opening the file, or run:

```sh
python3 -m http.server 8000
```

To publish the website separately at `https://alexdejongr.github.io`, create a public repository named `alexdejongr.github.io` and put `index.html` and `favicon.svg` at its root, then enable GitHub Pages from the `main` branch.

The profile README itself is `README.md`; GitHub renders that in the profile repository named `alexdejongr`.
